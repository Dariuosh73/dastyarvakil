راهنمای نصب دستیار وکیل روی هاست (نسخه ۱٫۲)

فایل‌ها: index.html (خود برنامه)، manifest.webmanifest و sw.js (برای نصب مثل برنامه و کار بدون اینترنت)، و چهار فایل آیکن.

شرط اصلی: نشانی سایت باید https باشد.

روش ۱: هاست معمولی
۱) همه‌ی فایل‌ها را در یک پوشه روی هاست آپلود کنید (مثلاً public_html/vakil).
۲) نشانی را باز کنید، مثلاً https://example.ir/vakil/

روش ۲: سرویس رایگان (Cloudflare Pages یا GitHub Pages یا Netlify)
۱) در سرویس حساب بسازید و یک پروژه‌ی تازه بسازید.
۲) همین فایل‌ها را آپلود کنید (در Netlify می‌توانید پوشه را بکشید و رها کنید).
۳) نشانی https که می‌دهد همان نشانی برنامه است.

نصب برای کاربر
- اندروید/کامپیوتر (Chrome): منو ← نصب برنامه (Install app)
- آیفون (Safari): دکمه‌ی اشتراک‌گذاری ← Add to Home Screen

بروزرسانی
فقط index.html را با نسخه‌ی تازه جایگزین کنید (و برای تازه شدن حافظه‌ی نهان، عدد C در sw.js را عوض کنید، مثلاً vakil-v1.3). کاربران با بازکردن برنامه نسخه‌ی تازه را می‌گیرند.

نکته‌ها
- داده‌ی هر کاربر فقط در مرورگر خودش می‌ماند و روی هاست ذخیره نمی‌شود.
- اگر نشانی سایت عوض شود، داده‌ها در نشانی جدید دیده نمی‌شود؛ پیش از جابه‌جایی از «پشتیبان‌گیری و داده‌ها» فایل پشتیبان بگیرید و در نشانی جدید بازگردانی کنید.
- پس از اولین باز شدن، برنامه بدون اینترنت هم باز می‌شود؛ فقط فونت وزیرمتن (Vazirmatn) بدون اینترنت جایگزین می‌شود.
